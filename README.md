# 비스토스 제품도우미

Windows PC에 등록한 제품 매뉴얼을 검색하고 로컬 Ollama로 출처가 있는 답변을 만드는 사내용 프로그램입니다. 한국어와 영어 화면, 사용자 계정, 문서 자료실, 제품 문의와 고장 상담을 지원합니다.

이 저장소는 운영본에서 추린 소스입니다. 매뉴얼, 서비스 기록, 검수된 원문 발췌, 계정 및 질문 기록, 원격 접속 설정, 모델 파일, 실행 바이너리와 운영 검증 자료는 포함하지 않습니다.

## 실행

1. Windows에 Python 3.12, uv와 Ollama를 준비합니다.
2. 저장소 폴더에서 아래 명령을 실행합니다.

```powershell
uv sync --frozen --python 3.12
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start.ps1
```

3. 브라우저에서 http://127.0.0.1:8765 를 열고 최초 관리자 계정을 만듭니다. 관리자 화면에서 제품과 사용 권한이 있는 매뉴얼을 등록하고 검토 후 게시합니다.
4. AI 답변을 쓰려면 Ollama가 `127.0.0.1:11434`에서 로컬 모델을 제공하도록 실행합니다. 모델 설정에서 설치된 로컬 모델을 선택합니다. 기존 운영 환경은 `qwen3.5:9b-q4_K_M`을 사용합니다.

새 설치에서는 `data/`에 별도의 데이터가 만들어집니다. 운영 데이터의 이전은 기존 백업 절차를 사용하세요. 원격 연결은 운영 환경에 맞게 별도로 설정합니다.
